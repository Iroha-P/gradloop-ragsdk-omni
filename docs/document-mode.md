# PDF / Word 文档模式

发布状态（2026-10-05）：代码与合成文件自动测试已完成，包含本地模块资源、文档分流和公开静态页面请求路由修复。Wrangler 4.76.0 已独立安装并验证版本，但 Cloudflare 身份请求未成功；当前在线页面尚未更新，仍为 `prepared_not_final`。Browser 保存权限校验未通过，真实浏览器验收和本轮 MAP 推理未验证，不绕过权限检查。

文档模式位于全模态训练台，与媒体上传分开。支持 PDF 文字层、DOCX 正文和 OLE 格式 DOC 正文；不是把“PDF”字样加到文件选择框中后仍返回演示 fixture。

媒体入口选择 PDF / DOC / DOCX 会自动切换至文档模式，仍需点击“解析文档（仅本机）”才读取正文；混选文档和媒体会明确拒绝。正文解析模块独立加载，不依赖实时模型模块初始化成功。离线基线不调用模型 API，模型发送按钮会显示未配置并保持禁用，本地解析与预览仍可使用。

已运行的本地服务须停止并重新启动，再强制刷新页面，才能加载新增资源路由；仅刷新不能更新运行中的后端代码。

公开静态页面默认进入文档模式，不向不存在的本地 `/v1/` 接口上传材料。MAP 正文分析只有在非空文字回复与完成事件均收到后才显示“本次推理完成”；“已配置”“连接中”与“会话就绪”不代表推理成功。

## 数据流

```text
用户选文件 → 浏览器内存 → 本地 Worker 解析 → 可编辑文本预览
                                           ↓ 用户明确确认
                                     MAP 文字会话 → 分析反馈
```

解析步骤不发起模型请求。文件字节只交给同源本地解析 Worker，不发送原文件、原文件名或本机路径。原文与结果不写入应用数据库、日志、localStorage 或 sessionStorage。页面关闭或清除后不保留本次内容。

模型分析单独确认发送：用户必须检查文本属于公开或合成内容，勾选许可并点击发送；文本与分析任务此时才经过现有 Worker 代理进入 MAP。不得向云端发送私人资料。第三方模型服务仍受其使用条款和保留政策约束，应用侧的“不持久化”不是对第三方服务的保证。

## 限制与错误

- 最多 4 份文档，每份 10 MB、合计 20 MB，PDF 最多 50 页，合并正文最多 12,000 字符。
- 每份本地解析 20 秒超时后终止 Worker；MAP 文本分析 45 秒后停止等待。
- MIME 与文件签名核验，DOCX 在解压前检查容器大小、条目数与压缩比。
- 扫描 PDF 无文字层时明确报错，不伪造 OCR。密码保护、损坏和不支持的 Word 变体报错，提示转换。
- 只提取正文，不承诺表格、公式、复杂排版、图片或批注的完整还原，不自动索引进 RAG。
- 不渲染转换所得 HTML，不执行宏、脚本、嵌入对象或外部关系链接。原文内指令作为不可信资料而非执行命令。
- 选择新文件、编辑文本会撤销发送确认；解析结果与异步会话均有取消和超时处理。

## 可复验组件

解析资产为固定版本 PDF.js、Mammoth 与 Word Extractor 的本地 bundle，见 [来源与哈希](../app/ui/documents/vendor/provenance.json)及 [第三方许可证](../app/ui/documents/vendor/THIRD_PARTY_NOTICES.md)。

重建：

```powershell
cd scripts/browser-documents
npm ci --ignore-scripts --no-audit --no-fund
npm run build
```

自动测试只生成合成 PDF、DOC、DOCX，不读取私人资料。真实浏览器实测和真实 MAP 输出须单独记录，不能用 Node 测试或合成回放替代。

发布扫描只对固定文件路径、精确 SHA-256 下的已审查 OSS 示例字面量与必要公共作者联系方式作消歧；任一字节变化或文件路径变化会撤销该例外。其它源码、文档、配置和输入检查不放宽。
